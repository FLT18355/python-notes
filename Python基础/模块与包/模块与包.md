# 模块与包

## 模块

模块就是 `.py` 文件，Python 中每个文件都是一个模块。

### 导入方式

```python
# 导入整个模块
import math
print(math.pi)

# 导入特定内容
from datetime import datetime
print(datetime.now())

# 重命名
import random as rnd
print(rnd.randint(1, 100))

# 导入多个
from os import path, listdir

# 导入所有（不推荐）
from math import *  # 可能覆盖同名变量
```

### if __name__ == "__main__"

```python
# my_module.py
def greet(name):
    return f"Hello, {name}!"


def main():
    print(greet("World"))


# 直接运行该文件时执行
if __name__ == "__main__":
    main()

# 被导入时不执行 main()
```

```python
# 在其他文件中导入
import my_module
print(my_module.greet("Python"))  # Hello, Python!
```

## 包

包是包含 `__init__.py` 文件的目录，用于组织多个模块。

### 创建包

```
my_package/
├── __init__.py
├── utils.py
├── models/
│   ├── __init__.py
│   └── user.py
```

`my_package/__init__.py`：

```python
# 包初始化文件
# 可以在这里导入子模块，方便外部使用
from .utils import helper
from .models import user
```

### 导入包

```python
# 导入包
import my_package

# 导入子模块
from my_package import utils
from my_package.models import user

# 导入具体函数
from my_package.utils import helper
```

## 标准库模块速查

| 模块 | 用途 |
|------|------|
| `os` | 操作系统接口 |
| `sys` | 系统相关 |
| `json` | JSON 处理 |
| `datetime` | 日期时间 |
| `random` | 随机数 |
| `re` | 正则表达式 |
| `math` | 数学函数 |
| `pathlib` | 路径处理 |
| `collections` | 高级数据结构 |
| `itertools` | 迭代器工具 |
| `functools` | 函数工具 |
| `typing` | 类型注解 |

## 虚拟环境

```bash
# 创建虚拟环境
python -m venv venv

# 激活
# Linux/Mac:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# 退出
deactivate

# 导出依赖
pip freeze > requirements.txt

# 安装依赖
pip install -r requirements.txt
```

## 常见实战

```python
# 工具模块 utils.py
def add(a, b):
    return a + b


def multiply(a, b):
    return a * b


# 主程序 main.py
from utils import add, multiply

if __name__ == "__main__":
    print(add(1, 2))
    print(multiply(3, 4))
```
