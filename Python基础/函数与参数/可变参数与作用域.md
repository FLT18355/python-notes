# 可变参数

## 可变位置参数（打包成元组）

```python
def test1(*args):
    print(args)


test1("你可以放多个参数", 1, 2, 3)  # --> ('你可以放多个参数', 1, 2, 3)
```

## 可变关键字参数（打包成字典）

```python
def test2(**kwargs):
    print(kwargs)


test2(
    a="你可以放多个关键字参数", b="game", c=1
)  # --> {'a': '你可以放多个关键字参数', 'b': 'game', 'c': 1}
```

## 同时使用

```python
def test3(*args, **kwargs):
    print(args)
    print(kwargs)


test3(1, 2, 3, a="4", b="5")
# 输出结果
# (1, 2, 3)
# {'a': '4', 'b': '5'}
```

可变位置参数、可变关键字参数，也能和其他类型的参数一起使用：

```python
# 顺序大概是这样子, 位置参数, 可变位置参数, 关键字参数, 可变关键字参数
def test4(a, b, *c, c2='go', **d):
    print(a)
    print(b)
    print(c)
    print(c2)
    print(d)


test4('你好', 'gay', '可变位置参数', 1, 2, 3, c='ubuntu', l1='可变关键字参数', l2=1)
```

## None — 特殊的字面量

- `None` 属于 `NoneType` 类型
- `None` 表示空值，没有意义
- `None` 转 `bool` 为 `False`

```python
a = None
```

### 返回值

`print` 函数没有返回值。

```python
def add(a, b):
    print(f'{a + b}')


result = add(100, 200)
# 这里 result 的返回值为 None
```

`return` 关键字会结束函数执行，并把 `return` 后面的值作为函数的返回值。

```python
def add(a, b):
    answer = a + b
    return answer
    # 这里可以直接写成 return a + b，如果这样子写 answer 就没有用了


result = add(100, 200)
# 这里 result 的返回值就是 300
```

## 全局作用域与局部作用域

```python
a = 100
b = 300


def add():
    # 属于局部变量
    c, d = 200, 400
    print(c, d)


add()
```

`global` 声明变量是全局变量：

```python
def a():
    global b
    b = 100
    # global 写在局部变量的上面
```

注意：局部变量与局部作用域会在函数调用的时候创建，在函数执行结束后销毁。全局作用域与全局变量会在程序开始时创建，在程序结束后销毁。

## 递归调用

> 所谓的递归调用就是自己调用自己
> 递归如果不做限制的话会一直陷入死循环

```python
def a(n):
    print(f'调用剩余次数{n - 1}')
    if n > 1:
        a(n - 1)


a(6)
```

### 如果要反着来呢？

```python
def a(n):
    if n > 1:
        a(n - 1)
    print(f'调用剩余次数{n - 1}')


a(6)
```

这回是先把 n 给扣光了，然后再打印，跟上面的不一样。

## 案例：阶乘

```python
def fac(num):
    if num == 0:
        return 1
    else:
        return num * fac(num - 1)
```

- `2! = 2 × 1`
- `0! = 1`
- `3! = 3 × 2 × 1`

注意：
```
n! = n × (n - 1)!
```
调用函数：`fac(5)`，这就是求五的阶乘。

## 函数说明文档

```python
def add(n1, n2):
    """函数的说明文档(使用三个单引号也行)"""
    return n1 + n2
```

```python
def add(n1, n2):
    """
    函数的说明文档(使用三个单引号也行)
    :param n1:第一个数字
    :param n2:第二个数字
    :return:两者相加的结果
    """
    return n1 + n2
```
