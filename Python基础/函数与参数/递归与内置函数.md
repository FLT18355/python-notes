# 递归与内置函数

## sum 内置函数

`sum` 是 Python 的内置函数，用于求和。

```python
def test(*awa):
    return sum(awa)


test(5, 85, 12, 35)
# 返回值就是 5 + 85 + 12 + 35 = 137
```

## 其他的小知识（回顾）

```python
print('%d, %.1f' % ("awa", 5.422775548511358821228712690054288721786244))
```

### 这样子也行

```python
print(f'{awa}, {a:.1f}')
```
