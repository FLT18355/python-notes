# 运算符

## 算术运算符

```python
a = 10
b = 3

a + b    # 加法 → 13
a - b    # 减法 → 7
a * b    # 乘法 → 30
a / b    # 除法 → 3.333...（结果永远是浮点数）
a // b   # 整除 → 3（取整）
a % b    # 取余（模运算）→ 1
a ** b   # 幂运算 → 1000（10 的 3 次方）
```

## 比较运算符

返回布尔值 `True` 或 `False`。

```python
a == b   # 等于
a != b   # 不等于
a > b    # 大于
a < b    # 小于
a >= b   # 大于等于
a <= b   # 小于等于
```

## 逻辑运算符

```python
# and：两边都为 True 才为 True
True and False   # → False

# or：任意一边为 True 就为 True
True or False    # → True

# not：取反
not True         # → False
```

### 短路求值

```python
x = 0 and 100    # → 0（第一个为假，不继续计算）
x = 100 or 0     # → 100（第一个为真，不继续计算）
```

## 赋值运算符

```python
a = 10
a += 5    # 等价于 a = a + 5 → 15
a -= 3    # → 12
a *= 2    # → 24
a /= 4    # → 6.0
a //= 2   # → 3.0
a %= 2    # → 1.0
a **= 3   # → 1.0
```

## 成员运算符

```python
"py" in "python"     # → True
"xyz" not in "abc"   # → True
```

## 身份运算符

```python
a = [1, 2, 3]
b = [1, 2, 3]
a is b           # → False（内容相同但对象不同）
a == b           # → True（内容相等）
a is a           # → True（同一个对象）
```

## 运算符优先级

从高到低大致顺序：

1. `**`
2. `+x, -x, ~x`（正负、取反）
3. `* / // %`
4. `+ -`
5. 比较运算符 `== != > < >= <=`
6. `not`
7. `and`
8. `or`

不记得时用括号 `()` 最保险喵~
