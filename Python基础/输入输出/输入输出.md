# 输入与输出

## print() 输出

### 基本用法

```python
print("Hello, World!")
print(42)
print(3.14, "pi", True)
```

### 格式化输出

```python
name = "蓝汐"
age = 18

# f-string（推荐）
print(f"{name} 今年 {age} 岁")

# 占位符
print("%s 今年 %d 岁" % (name, age))
print("{} 今年 {} 岁".format(name, age))
```

### 控制输出

```python
print("hello", end="")      # 不换行
print("world")              # → helloworld

print("a", "b", "c", sep="-")  # → a-b-c
```

## input() 输入

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

`input()` 返回的永远是字符串类型，需要转换时用类型转换：

```python
age = int(input("请输入年龄："))
height = float(input("请输入身高："))
```

## 综合示例

```python
print("===== 个人信息录入 =====")
name = input("姓名：")
age = int(input("年龄："))
score = float(input("分数："))

print(f"\n你好，{name}！")
print(f"年龄：{age} 岁")
print(f"分数：{score:.1f} 分")
```
