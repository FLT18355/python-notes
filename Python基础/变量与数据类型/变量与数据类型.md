# 变量与数据类型

## 变量的定义

变量是程序中用于存储数据的容器，通过赋值语句创建。

```python
name = "蓝汐"
age = 18
height = 1.65
is_student = True
```

## 基本数据类型

### 整数（int）

```python
a = 10
b = -5
c = 0
```

### 浮点数（float）

```python
pi = 3.14159
price = 19.9
```

### 字符串（str）

```python
greeting = "你好，世界"
slogan = 'Python is awesome'
```

### 布尔值（bool）

```python
is_ok = True
is_done = False
```

### 空值（None）

```python
nothing = None
```

## type() 查看类型

```python
print(type(10))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>
print(type(None))      # <class 'NoneType'>
```

## 类型转换

```python
int("123")     # 字符串转整数 → 123
float("3.14")  # 字符串转浮点 → 3.14
str(100)       # 整数转字符串 → "100"
int(3.14)      # 浮点转整数 → 3（截断小数部分）
bool(0)        # 整数转布尔 → False
bool(1)        # 整数转布尔 → True
```

## 动态类型

Python 是动态类型语言，同一个变量可以指向不同类型的值。

```python
x = 10        # x 现在是 int
x = "hello"   # x 现在是 str，不会报错
```
