# 字符串

## 创建字符串

```python
s1 = '单引号'
s2 = "双引号"
s3 = """三引号可以
跨多行书写"""
```

## 字符串运算

```python
"hello" + "world"    # 拼接 → "helloworld"
"ha" * 3             # 重复 → "hahaha"
"py" in "python"     # 成员判断 → True
len("python")        # 长度 → 6
```

## 索引与切片

```python
s = "Python"

s[0]      # → 'P'（正索引）
s[-1]     # → 'n'（负索引）
s[1:4]    # → 'yth'（左闭右开）
s[:3]     # → 'Pyt'（从头到索引2）
s[2:]     # → 'thon'（从索引2到尾）
s[::2]    # → 'Pto'（步长为2）
s[::-1]   # → 'nohtyP'（反转）
```

## 常用方法

```python
s = "  hello python  "

s.strip()        # → 'hello python'（去除两端空白）
s.lstrip()       # → 'hello python  '（去除左侧空白）
s.rstrip()       # → '  hello python'（去除右侧空白）

s.upper()        # → '  HELLO PYTHON  '
s.lower()        # → '  hello python  '
s.title()        # → '  Hello Python  '

s.replace("python", "world")  # → '  hello world  '

s.split()        # → ['hello', 'python']（按空白分割）
s.split(",")     # → ['hello python']（按逗号分割）

"-".join(["a", "b", "c"])  # → 'a-b-c'

s.startswith("h")  # → True
s.endswith("n")    # → False

s.find("py")       # → 7（找不到返回 -1）
s.count("l")       # → 2
```

## 字符串格式化

### f-string（推荐）

```python
name = "蓝汐"
age = 18
f"{name} 今年 {age} 岁啦~"  # → "蓝汐 今年 18 岁啦~"
```

### format 方法

```python
"{} 今年 {} 岁".format(name, age)
"{0} + {1} = {2}".format(1, 2, 3)
```

### % 格式化

```python
"%s 今年 %d 岁" % (name, age)
```

## 转义字符

```python
"\n"   # 换行
"\t"   # 制表符（Tab）
"\\"   # 反斜杠
"\""   # 双引号
```

## 原始字符串

```python
r"C:\Users\name"  # 忽略转义字符
```
