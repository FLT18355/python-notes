# 元组（tuple）

## 创建元组

```python
# 直接创建
t1 = (1, 2, 3)
t2 = ("a", "b", "c")
t3 = (1, "hello", True)  # 可以存放不同类型

# 单元素元组（注意逗号！）
t4 = (1,)          # 这是元组
t5 = (1)           # 这只是整数，不是元组

# 空元组
t6 = ()
t7 = tuple()

# 从列表转换
t8 = tuple([1, 2, 3])
```

## 元组的特性

**不可变**：一旦创建，不能增删改元素。

```python
t = (1, 2, 3)
t[0] = 99    # ❌ TypeError: 'tuple' object does not support item assignment
```

但如果元组里包含可变对象（如列表），那个对象本身仍然可以修改：

```python
t = (1, [2, 3])
t[1].append(4)    # → (1, [2, 3, 4])，允许的
```

## 索引与切片

```python
t = ("a", "b", "c", "d", "e")

t[0]      # → 'a'
t[-1]     # → 'e'
t[1:3]    # → ('b', 'c')
t[::2]    # → ('a', 'c', 'e')
```

## 常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `count(x)` | 统计 x 出现次数 | `t.count(1)` |
| `index(x)` | 返回第一个 x 的下标 | `t.index("b")` |

## 为什么用元组？

1. **不可变**，数据安全，不会被意外修改
2. **性能更好**，比列表更省内存、访问更快
3. **可以作为字典的键**（列表不行）
4. **函数返回多个值**本质就是返回元组

```python
def min_max(nums):
    return min(nums), max(nums)


low, high = min_max([3, 1, 4, 2])  # 解包赋值
print(low, high)  # → 1 4
```

## 元组解包

```python
a, b, c = (1, 2, 3)
print(a, b, c)  # → 1 2 3

# 交换变量
x, y = 10, 20
x, y = y, x     # → x = 20, y = 10

# 星号表达式
first, *middle, last = (1, 2, 3, 4, 5)
# → first = 1, middle = [2, 3, 4], last = 5
```
