# 集合（set）

## 创建集合

```python
# 直接创建
s1 = {1, 2, 3, 3}    # 重复元素自动去重 → {1, 2, 3}
s2 = {"a", "b", "c"}

# 空集合（注意：{} 是空字典！）
s3 = set()

# 从列表转换
s4 = set([1, 2, 2, 3])  # → {1, 2, 3}
```

## 集合的特性

- **无序**：元素没有固定顺序，不能用下标访问
- **不重复**：自动去重
- **可变**：可以增删元素，但元素本身必须是不可变类型（int、str、tuple）

```python
s = {1, 2, 3}
s.add(4)        # → {1, 2, 3, 4}
s.add(2)        # → {1, 2, 3, 4}（2 已存在，无变化）

s.remove(2)     # → {1, 3}（不存在的元素会报错）
s.discard(10)   # → {1, 3}（不存在的元素静默跳过）
s.pop()         # 随机删除并返回一个元素
s.clear()       # 清空
```

## 数学运算

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# 交集
a & b              # → {3, 4}
a.intersection(b)  # → {3, 4}

# 并集
a | b              # → {1, 2, 3, 4, 5, 6}
a.union(b)         # → {1, 2, 3, 4, 5, 6}

# 差集（a 中有但 b 中没有）
a - b              # → {1, 2}
a.difference(b)    # → {1, 2}

# 对称差集（只在其中一个集合中）
a ^ b              # → {1, 2, 5, 6}
a.symmetric_difference(b)  # → {1, 2, 5, 6}
```

## 成员判断

```python
s = {1, 2, 3}
1 in s      # → True
4 in s      # → False
```

## 集合推导式

```python
squares = {x ** 2 for x in range(6)}
# → {0, 1, 4, 9, 16, 25}
```

## 不可变集合（frozenset）

```python
fs = frozenset([1, 2, 3])
# 不可增删，但可以作为字典的键或其他集合的元素
```

## 什么时候用集合？

- 去重
- 成员判断（比列表快）
- 数学运算（交集、并集、差集）
