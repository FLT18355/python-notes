# 字典（dict）

## 创建字典

```python
# 直接创建
d1 = {"name": "蓝汐", "age": 18, "city": "月光湖"}
d2 = dict(name="蓝汐", age=18, city="月光湖")

# 空字典
d3 = {}
d4 = dict()

# 从键值对列表创建
d5 = dict([("a", 1), ("b", 2), ("c", 3)])
# → {'a': 1, 'b': 2, 'c': 3}

# 字典推导式
d6 = {x: x ** 2 for x in range(5)}
# → {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

## 字典的特性

- **键值对（key-value）**存储
- **键（key）必须不可变**（str、int、float、tuple 等）
- **值（value）可以是任意类型**
- Python 3.7+ 字典保持插入顺序
- **键不能重复**，重复赋值会覆盖

```python
d = {"a": 1, "b": 2, "a": 3}  # → {'a': 3, 'b': 2}（a 被覆盖）
```

## 增删改查

### 查询

| 方式 | 说明 | 示例 |
|------|------|------|
| `d[key]` | 取值，不存在则报错 | `d["name"]` |
| `d.get(key)` | 取值，不存在返回 None | `d.get("age")` |
| `d.get(key, 默认值)` | 不存在返回默认值 | `d.get("city", "未知")` |
| `key in d` | 判断键是否存在 | `"name" in d` |

```python
d = {"name": "蓝汐", "age": 18}

print(d["name"])        # → 蓝汐
print(d["city"])        # ❌ KeyError
print(d.get("city"))    # → None
print(d.get("city", "月光湖"))  # → 月光湖
```

### 新增 / 修改

```python
d = {}
d["name"] = "蓝汐"    # 新增 → {"name": "蓝汐"}
d["age"] = 18         # 新增 → {"name": "蓝汐", "age": 18}
d["age"] = 19         # 修改 → {"name": "蓝汐", "age": 19}
```

### 删除

| 方法 | 说明 | 示例 |
|------|------|------|
| `del d[key]` | 删除指定键 | `del d["age"]` |
| `d.pop(key)` | 删除并返回值 | `d.pop("age")` |
| `d.pop(key, 默认值)` | 不存在返回默认值 | `d.pop("age", 0)` |
| `d.popitem()` | 删除并返回最后一对键值 | `d.popitem()` |
| `d.clear()` | 清空字典 | `d.clear()` |

## 常用方法

```python
d = {"a": 1, "b": 2, "c": 3}

# 获取所有键
d.keys()       # → dict_keys(['a', 'b', 'c'])

# 获取所有值
d.values()     # → dict_values([1, 2, 3])

# 获取所有键值对
d.items()      # → dict_items([('a', 1), ('b', 2), ('c', 3)])

# 更新字典（合并）
d.update({"d": 4, "a": 10})  # → {"a": 10, "b": 2, "c": 3, "d": 4}
```

## 遍历字典

```python
d = {"name": "蓝汐", "age": 18, "city": "月光湖"}

# 遍历键
for key in d:
    print(key)

# 遍历值
for value in d.values():
    print(value)

# 遍历键值对
for key, value in d.items():
    print(f"{key}: {value}")
```

## 字典推导式

```python
squares = {x: x ** 2 for x in range(5)}
# → {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 带条件过滤
evens = {x: x ** 2 for x in range(10) if x % 2 == 0}
# → {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}
```

## 默认字典（collections.defaultdict）

```python
from collections import defaultdict

dd = defaultdict(int)
dd["a"] += 1    # → {"a": 1}（无需先判断 key 是否存在）
```

## 什么时候用字典？

- 通过唯一标识查找数据（如用户 ID → 用户信息）
- 数据映射关系
- 统计计数
