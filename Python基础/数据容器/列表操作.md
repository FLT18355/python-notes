# 数据容器

- 一种能存放多个数据的数据类型
- 容器中的每一个数据，又称：每一个元素
- Python 中有很多种数据类型：
  - 字符串
  - 元组
  - 列表
  - 集合
  - 字典

## 列表（list）

**示例**：

元素 0, 元素 1, 元素 2，从 0 开始。

```python
a = ["元素0", "元素1", "元素2"]
# 也可以套娃
b = [1, 3, [5, 6]]

# 也可以定义空列表
c = []
d = list()
```

`list()` 是 Python 中的内置函数。

### 列表 — 下标（索引值）

> 所谓下标，就是指列表中元素的位置编号
> 分为两种，分别为正索引和负索引

- **正索引**：从左往右数，起始元素是 0，随后是 1，以此类推
- **负索引**：从右往左数，起始元素是 -1，随后 -2，以此类推

可以通过 `列表[下标]` 的形式，取出对应元素。

```python
nums = [1, 5, [3, 47], 145]
print(nums[2][1])  # 输出 47
```

### 列表 — 增删改查

> 增删改查指的是：新增、删除、修改、查询（C、D、U、R）

#### 新增

- 方式一：在列表尾部追加一个元素（语法：`列表.append(元素)`）
- 方式二：在列表指定下标处添加一个元素（语法：`列表.insert(下标, 元素)`）`nums.insert(2, 250)`
- 方式三：将可迭代对象中的内容依次取出，追加到列表尾部（语法：`列表.extend(可迭代对象)`）`nums.extend([78, 91, 13])`

#### 删除

- 方式一：`del 列表[下标]`
- 方式二：`列表.pop(下标)`，返回被删除的元素
- 方式三：`列表.remove(元素)`，删除第一个匹配的元素
- 方式四：`列表.clear()`，清空列表

#### 修改

直接通过下标赋值：

```python
nums[0] = 100
```

#### 查询

```python
print(nums[0])        # 根据下标查询
print(nums.index(5))  # 根据值查询下标
```
