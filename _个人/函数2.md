```python
# 可变参数
# 可变位置参数[打包成元组]
def test1(*args):
    print(args)


test1("你可以放多个参数", 1, 2, 3)  # --> ('你可以放多个参数', 1, 2, 3)

# 可变关键字参数(在形参名前加**)[打包成字典]


def test2(**kwargs):
    print(kwargs)


test2(
    a="你可以放多个关键字参数", b="game", c=1
)  # --> {'a': '你可以放多个关键字参数', 'b': 'game', 'c': 1}


# 可变位置参数, 可变关键字参数, 可以同时使用, 但必须先写可变位置参数
def test3(*args, **kwargs):
    print(args)
    print(kwargs)


test3(1, 2, 3, a="4", b="5")
# 输出结果
# (1, 2, 3)
# {'a': '4', 'b': '5'}
```
# 可变位置参数, 可变关键字参数,也能和其他类型的参数一起使用
```python
# 顺序大概是这样子, 位置参数, 可变位置参数, 关键字参数, 可变关键字参数
def test4(a, b, *c, c2='go', **d):
	print(a)
	print(b)
	print(c)
	print(c2)
	print(d)

test4('你好', 'gay', '可变位置参数', 1, 2, 3, c='ubuntu', l1='可变关键字参数', l2=1)
```

return关键字: return会*结束函数执行*, 并把return后面的*值*, 作为**函数的返回值**
```python
def add(a, b):
	answer = a + b
	return answer
	# 这里可以直接写成return a + b, 如果这样子写answer就没有用了
result = add(100, 200)
# 这里result的返回值就是300
```

```python

def add():
```

`global`声明变量是**全局***变量*

```python
def a():
    global b
    b = 100
    # global写在局部变量的上面
```

## 注意: 局部变量与局部作用域会在函数调用的时候创建, 在函数执行结束后销毁. 全局作用域与全局变量会在程序开始时创建, 在程序结束后销毁

# 递归调用

> 所谓的递归调用就是自己调用自己
> 递归如果不做限制的话会一直陷入死循环

```python
def a(n):
    print(f'调用剩余次数{n - 1}')
    if n > 1:
        a(n - 1)

a(6)
```

## 如果要反着来呢？

```python
def a(n):
    if n > 1:
        a(n - 1)
    print(f'调用剩余次数{n - 1}')
                
a(6)
```

这回是先把n给扣光了, 然后再打印, 跟上面的不一样.

## 案例

```python
def fac(num):
    if num == 0:
        return 1
    else:
        return num * fac(num - 1)
```

这是一个求阶乘的函数
2! = 2 x 1
0! = 1
3! = 3 x 2 x 1
*注意*:
    n! = n x (n - 1)!
就像这样子
调用函数:
`fac(5)`, 这就是求五的阶层
