```python

# 也可以定义空列表
c = []
d = list()
```

**list()**是Python中的***内置函数***

## 列表 - 下标 (索引值)

> 所谓下标, 就是指列表中元素的位置编号
> 分为两种, 分别为正索引和负索引

- 索引
 - 正: 从**左往右数**, 起始元素是0, 随后是1, 以此类推
 - 负: 从**右往左数**, 起始元素是-1, 随后-2, 以此类推
 
可以通过: `列表[下标]`的形式, 取出对应元素

```python
nums2 = [1, 5, [3, 47], 145]
print(nums[2][1])
```

## 列表 - 增删改查

> 增删改查指的是: 新增，删除，修改，查询(C, D, U, R)

### 新增

- 方式
 - 方式一: 在列表尾部追加一个元素(语法:列表.append(元素))
 - 方式二: 在列表指定下标处添加一个元素(语法:列表.insert(下标, 元素)) `nums.insert(2, 250)`
 - 方法三: 将可迭代对象中的内容依次取出, 追加到列表尾部(语法:列表.extend(可迭代对象)) `nums.extend([78, 91, 13])`
