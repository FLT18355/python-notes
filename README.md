# Python 学习笔记

个人 Python 学习过程中的笔记与练习代码。

## 内容概览

### 基础概念
- 函数定义与调用（位置参数、关键字参数、默认参数）
- 可变参数（`*args`、`**kwargs`）
- 数据容器（列表、元组、集合、字典）
- `None` 与特殊字面量

### 标准库速查
- **JSON 处理** — `json.dumps()` / `json.loads()` 编码与解码
- **路径操作** — `pathlib.Path` 面向对象路径管理
- **文件操作** — `with open()` 上下文管理器最佳实践

## 用途

- 日常练习代码片段
- 快速查阅常用语法与 API
- 学习回顾与知识沉淀
